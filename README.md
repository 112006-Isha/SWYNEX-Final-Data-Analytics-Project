# Global Electronics Retail Analysis

## 1. Project Overview

This project focuses on analyzing the Global Electronics Retail dataset through data cleaning, exploratory data analysis, and interactive dashboard creation.

The project is divided into four tasks:

- Task 1 – Data Cleaning
- Task 2 – Exploratory Data Analysis
- Task 3 – Interactive Dashboard
- Task 4 – Final Project Submission

---

## 2. Problem Statement

The objective of this project is to clean and analyze a public retail dataset, identify important trends, patterns and anomalies, and present the findings through an interactive Power BI dashboard.

The project aims to transform raw retail data into meaningful insights that can support better understanding of sales, customers, products, orders and delivery performance.

---

## 3. Dataset Information

The Global Electronics Retail dataset contains multiple tables related to:

- Sales
- Products
- Customers
- Stores
- Exchange Rates

The dataset was used for data cleaning, exploratory analysis and dashboard development.

---

## 4. Task 1 – Data Cleaning

### Objective

Clean the raw dataset and prepare it for further analysis.

### Cleaning Process

The following data quality checks and cleaning steps were performed:

- Identified and checked missing values
- Checked for duplicate records
- Checked incorrect data types
- Identified inconsistent values and formats
- Corrected data formats and data types where required
- Prepared the cleaned dataset for analysis

### Tool Used

Microsoft Excel

### dataset used

Maven Analytics

The cleaned dataset is included in the `Task 1 & 2 - Excel EDA` folder.

---

## 5. Task 2 – Exploratory Data Analysis

### Objective

Perform exploratory analysis using the cleaned dataset to identify important statistics, trends, patterns and anomalies.

### Analysis Performed

- Created PivotTables
- Performed important calculations
- Analyzed orders and quantities
- Analyzed products and categories
- Analyzed customers and countries
- Analyzed delivery trends
- Created charts and visualizations
- Identified trends, patterns and anomalies
- Identified five useful business insights

### Tool Used

Microsoft Excel

The complete Excel analysis is included in the `Task 1 & 2 - Excel EDA` folder.

---

## 6. Task 3 – Interactive Power BI Dashboard

### Objective

Create an interactive dashboard to clearly communicate the main findings from the analysis.

### Dashboard Components

The Power BI dashboard contains:

- KPI cards
- Orders trend analysis
- Orders by country
- Quantity sold by category
- Top 10 products by quantity sold
- Orders by store location
- Delivery time analysis
- Key insights

### Filters

Useful filters can be used to explore the dashboard based on different aspects of the dataset.

### Tool Used

Microsoft Power BI

The Power BI dashboard file is included in the `Task 3 - Power BI Dashboard` folder.

---

## 7. Key Business Insights

1. 2019 recorded the highest number of orders.

2. Computers had the highest quantity sold among the product categories.

3. The United States recorded the highest number of orders.

4. iPhone 13 was the top-selling product by quantity.

5. Most orders were delivered around 4 days, while some negative delivery values were identified and require further review.
